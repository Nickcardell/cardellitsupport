# Cardell IT Support (site)

Static GitHub Pages site for **Cardell IT Support**.

- Repo: https://github.com/cardellexhibits/cardellitsupport
- Pattern: same as [cardellexhibits.github.io](https://github.com/cardellexhibits/cardellexhibits.github.io) — static HTML, push to `main`, Pages deploys.
- Intended custom domain: `cardellitsupport.com` (pending registration).

## Deploy

1. Settings → Pages → Source: Deploy from branch `main` / root (or `/docs` if changed).
2. After domain purchase: set `CNAME` to `cardellitsupport.com`, add DNS at registrar, verify in GitHub Pages.
3. Agents: read `AGENTS.md` before editing public copy.

## Claude Code

Open this repo and follow `AGENTS.md`. Replace the scaffold `index.html` with the real one-pager. Keep it static.
